## How to prioritize applications (practical)

1. **Lead packet:** this README + Critical CI narrative + “AI-directed systems design” frame.  
2. **Tier A first wave (5–10 apps):** OpenAI Agent Security, Anthropic FRT/Safeguards, Microsoft AI Red Team, HiddenLayer, Protect AI, METR-style orgs.  
3. **Parallel Tier C:** one clearance-friendly contractor pipeline if reactivation is acceptable.  
4. **Do not lead with** file counts, CVE dump sizes, or “I coded every line.”  
5. **Do lead with** resolved Criticals + agent memory/process design + threshold-vault *design* language.

## Compensation orientation (order-of-magnitude, not offers)

Public listings and market chatter for AI red team / safeguards / agent security at frontier labs often land in **senior security / research engineer** bands (total comp highly location- and level-dependent; Anthropic/OpenAI ranges publicly discussed in the high-six to seven-figure TC band for senior research/red-team seats—**not a promise**). Product-security startups and contractors are typically lower cash, sometimes with equity or clearance premium.

Treat numbers as research homework per posting—not guarantees.
